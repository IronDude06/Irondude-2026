# Irondude 2026

Installierbares, offlinefähiges Scoreboard für GitHub Pages.

## Enthaltene Dateien

- `index.html` – vollständige Anwendung
- `manifest.webmanifest` – App-Name, Darstellung und Symbole
- `service-worker.js` – Offline-Cache
- `icons/` – Symbole für iPhone und andere Geräte
- `.nojekyll` – verhindert eine unnötige Jekyll-Verarbeitung

Der Spielstand wird automatisch im Browser gespeichert. Über **Speichern** lässt sich zusätzlich eine JSON-Sicherung erzeugen; über **Spielstand laden** kann sie wieder eingelesen werden.
