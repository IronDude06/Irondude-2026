# Irondude 2026

Installierbares Scoreboard fuer GitHub Pages.

## Veröffentlichung

Alle Dateien und Ordner aus diesem Verzeichnis in die oberste Ebene des GitHub-Repositorys hochladen. GitHub Pages anschließend aus dem Branch `main` und dem Ordner `/ (root)` veröffentlichen.

Die Spielerfotos liegen im Ordner `players` und werden für die Spielkarten sowie die Gesamtwertung verwendet.


## Design
Die Oberfläche nutzt die Rot-Gold-Weiß-Palette und die Badge-/Surf-Gestaltung der Irondude-Barcelona-Vorlage.
